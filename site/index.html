FIELD NOTES / 2026.11.06

Guang’s Homelab

一套为家庭网络、影音和照片而建的自托管环境。Mac mini 负责网络服务，Synology 保存数据并承载应用，UniFi 连接整个家庭网络。

01 / INFRASTRUCTURE

架构与设备

GATEWAY

UniFi UDM SE

家庭网关，负责局域网与互联网之间的连接。

COMPUTE

Mac mini M4

运行 AdGuard Home、SmartDNS、Nginx Proxy Manager，并承担 Immich 机器学习任务。

STORAGE

Synology DS925+

24 GB 内存，存放影音和照片，承载家庭应用与监控服务。

02 / APPLICATIONS

家庭服务

影音

Emby 管理媒体库，Ani-RSS 订阅动画更新。

照片

Immich 管理照片。照片库和机器学习任务分布在两台主机上。

看板与监控

Glance 汇总服务，Glances 查看主机指标，Uptime Kuma 检查服务可用性。

03 / OPERATIONS

网络与维护

DNS
AdGuard Home 接收查询，SmartDNS 按域名选择上游。
反向代理
Nginx Proxy Manager 转发应用请求。
恢复
Docker Compose 记录部署结构，镜像固定到摘要。恢复时分别准备配置与应用数据。

从私有备份恢复的配置

Emby、Sublarr、Uptime Kuma 和 Apprise 的运行设置由应用保存在配置目录或数据库中。恢复时需准备对应备份。Immich 数据库和照片、NPM 数据库与证书也需要单独恢复。

07 / RESTORE

恢复与配置依赖

  1. 从 .env.example 创建各主机的本地环境文件，并从私有备份恢复密钥。
  2. 恢复 Emby、Kuma、Immich PostgreSQL 和照片数据，以及 NPM 数据和证书。保留 Sublarr 的四个补丁挂载。
  3. 按目标主机创建缺失的 Docker 网络。qBittorrent 连接隔离控制网络和 macvlan，Mac mini 上的 DNS 使用 host 网络。
  4. 在对应主机先运行 bash scripts/current.sh check nas 或 bash scripts/current.sh check macmini。检查通过后，将 check 换成 apply。同一 Compose 项目分布在多个文件中，恢复时须避免使用 --remove-orphans。
